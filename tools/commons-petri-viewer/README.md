# Petri Dish Replay Viewer v0.1

> **Next-generation system design:** [Biological Automata & Microscope v0.2](../../docs/BIOLOGICAL_AUTOMATA_MICROSCOPE_V02.md). This document describes a future integrated machine-level simulator and visual instrument. The present viewer is still a *categorical commons replay*, not that new spatial/biophysical simulator.

This is an **actual replay viewer** driven by existing `RenewableCommonsV0` results, not a separate toy simulation.

## Launch

From repository root:

```bash
dotnet run --project Tests/Headless/Cells.HeadlessChecks.csproj -- --commons-learned-pair artifacts/petri-replay
```

Open `tools/commons-petri-viewer/index.html` in a web browser and select **full.csv** for 100% reception and **half.csv** for 50% reception. Or download them from the `commons-petri-replays` CI artifact in the headless research workflow.

The two CSVs share the same test world seed (1010000), 400-episode training procedure, frozen learned follower policies, initial world distribution, and sender rule. Only message reception probability changes. Later world trajectories can diverge due to agent actions.

## Honest spatial abstraction

**The Petri dish is a categorical/diagrammatic map.** Current commons physics has *three discrete resource patches*, not Cartesian cell coordinates or fluid mechanics. The three fixed patch centers and their circles are **presentation coordinates**. Each agent is drawn adjacent to the resource patch in which its latest recorded harvest/restoration action occurred. Idle/signaling positions remain at their last displayed patch. No animated physical displacement is claimed. The numerals, energies, actions and messages are read from the authoritative trace and not generated by the viewer.

Recorded `observation` rows indicate signals heard by that particular follower, not all recipients; `signal` records the action sent. `repair-success` reports a total number of successful patches (not the individual patch) because per-patch success is not exposed by the current trace.

## Visual design

- Two circular dark Petri dishes, side by side, responsive to smaller screens
- Minimal double-line membranes for dish and thin-line ring for each cell
- Three color-coded resource regions (stock values inside)
- Four agent circles: amber scripted sender, mint frozen trained follower
- Standard iconography: ⚑ signal, ⌁ heard, ↘ harvest, ♻ restoration attempt, ✓ joint success, × death
- Shared synchronized play/pause, step and reset
- Click/keyboard-select individual agents to inspect their energy, last observation and actions
- Chronological current-tick event list grounded in CSV data

## Verification and remaining work

Headless CI builds and exports reproducible paired experiment traces. **The visual browser code itself still requires browser-level interaction testing**. Future iteration should add a versioned JSON state/event trace with initial stocks, exact patch-local restoration outcomes, per-recipient delivery counts, full observations and Q values, so the viewer needs no partial-state reconstruction.

The biology-oriented microscope remains a **separate Unity development track**, and these diagrams cannot serve as measured biophysical visualizations.
