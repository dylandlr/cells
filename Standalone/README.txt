cells — STANDALONE WINDOWS PROTOTYPE
====================================
Double-click Cells.exe. Requires Windows 10/11 x64. No Unity or .NET installation is required.

Controls:
  SPACE  Pause / resume
  R      Reset with new seeded ecosystem
  1/2/3  Slow / medium / fast simulation
  F      Choose nutrients for left-click
  T      Choose toxin for left-click
  C      Toggle visible chemistry heat map
  Left click on world: add selected substance
  Right click on world: add toxin
  ESC    Exit

Watch cells swim toward chemical gradients, metabolize available food,
release chemical signals, reproduce when energy is plentiful, or die.

IMPORTANT: This is a simplified playable prototype of cells developed
separately from the full Unity project. It is NOT the Unity executable.
It is NOT scientifically calibrated and does not include the full
game-theoretic EXP3 research, field/fluid mechanics or microscopy scene.

The standalone build is unsigned and Windows Smart App Control may block it.
Do not disable Windows security protections solely to execute an untrusted binary.
Verify the downloaded package's GitHub repository and provenance.
